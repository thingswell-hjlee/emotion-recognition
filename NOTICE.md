### English

This application uses a camera and microphone.

- Please obtain user consent before testing.
- Generated logs may include device information, performance metrics, and analysis results.
- By default, raw face/audio data should not be stored. If raw data recording is added, explicit consent is required.
- Face recognition results are processed locally only and are not transmitted to external servers.
- Voice data is discarded after STT processing; raw recordings are not stored.
